
"Bogdan - Miere din Marginimea Sibiului"

LIVE DEMO => https://honey-shop-fs.vercel.app/

The frontend (REACT+VITE) is deployed on Vercel.

"Bogdan - Miere din Marginimea Sibiului" is a web application developed as volunteer work for a local honey producer from Sibiu. The project aims to provide a clean, modern, and responsive online presentation for natural honey products, focusing on simplicity, clarity and a visually appealing user experience.

The application includes a product showcase, brand presentation, and a responsive layout optimized for mobile devices (@media css queries).

The app was built as a practical exercise 


The project was developed collaboratively to support a local business in presenting its honey products online while also serving as hands-on experience in web development. It demonstrates modern development practices such as modular architecture,  responsive UI or routing.

The project structure and design were built to adapt to different client requirements. Depending on the needs of the honey producer, the application can be customized to include additional pages, product categories, branding elements, or extended with backend functionality.


#Technologies Used

- React
- Vite
- TypeScript
- CSS Modules
- Responsive Design (CSS @media queries)


#Features
- Responsive design optimized for mobile and desktop browsers
- Product showcase with images and descriptions
- Modular component structure
- Backend prepared for future expansion (auth, admin dashbord, product management etd)
